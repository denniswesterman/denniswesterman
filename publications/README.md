## Repository convention

- English is the primary publication language and profile entry point.
- Dutch translations use identical, language-neutral slugs under `publications/nl/`.
- Each paper links directly to its language counterpart and the matching profile overview.
- Shared visual assets are stored once under [`assets/`](../assets/).
